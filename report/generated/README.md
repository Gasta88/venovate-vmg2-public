hand-edit — regenerated by `make all`.

`openalex_landscape.md` lists institution names from the committed OpenAlex
authorship marginals, each row carrying its public OpenAlex institution ID.
The internal-register leak sweep (G-7 / #27) therefore covers the hand-written
report prose only (`report/*.md`, top level); names appearing in this
directory are public data, not target leaks
(decisions.md 2026-10-01 "Biosecurity sweep scope" ruling).
